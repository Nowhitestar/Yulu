# Yulu

Yulu turns recorded conversations into durable, searchable notes. This glossary
names the user journey from obtaining Yulu to receiving the first complete note.

## Language

**Onboarding**:
The guided journey shared by first-time users, upgrading users, and developers,
adapted to their existing state and ending at Core Activation.
_Avoid_: First-run wizard, installation wizard

**Core Activation**:
The point when a user completes a real recording and receives its saved audio,
transcript, and Hermes-generated summary.
_Avoid_: Installation complete, setup complete
