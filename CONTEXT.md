# Yulu

Yulu turns recorded conversations into durable, searchable notes. This glossary
names the user journey from obtaining Yulu to receiving the first complete note.

## Language

**Onboarding**:
The guided journey shared by first-time users, upgrading users, and developers,
adapted to their existing state and ending at Core Activation.
_Avoid_: First-run wizard, installation wizard

**Core Activation**:
The point when a user completes a real recording and receives its saved audio,
transcript, and a summary generated by the explicitly selected Summary Provider.
_Avoid_: Installation complete, setup complete

**Summary Provider**:
The explicitly selected source of recording summaries: either a supported Agent
connected through OAuth or a model service connected directly with an API key.
The selection is fixed for each recording task and never changes automatically.
_Avoid_: Summary Agent, fallback provider

**Onboarding Completion**:
The point after Core Activation when every optional capability has either been
activated or explicitly deferred by the user.
_Avoid_: Every integration enabled
