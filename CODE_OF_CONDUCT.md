# Code of Conduct

The Yulu project follows the **Contributor Covenant**, version 2.1.

The full text — covering expected behavior, unacceptable behavior, enforcement responsibilities, and the enforcement ladder (correction → warning → temporary ban → permanent ban) — lives at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project (issues, pull requests, discussions, or any other channel) you agree to abide by it.

## Reporting

If you experience or witness behavior that violates the covenant, contact the project maintainer:

- **Email:** nowhitestar@gmail.com
- **GitHub:** open a private security advisory at <https://github.com/Nowhitestar/Yulu/security/advisories/new> (yes, the security advisory channel — it's the only private channel this repo has, and the maintainer reads it)

Reports are kept confidential. The maintainer aims to respond within **3 business days**.

## Scope

This applies to all project spaces — the GitHub repository, issues, pull requests, Discussions, and any future channels (mailing list, chat, etc.) — and to public spaces when an individual is officially representing the project.
