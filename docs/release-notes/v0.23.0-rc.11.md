# Yulu v0.23.0-rc.11

This candidate supersedes RC10 after installed-App validation exposed missing
native recording controls and an isolated local-caption startup failure.

- **recording controls** — the product App now owns its menu-bar controls,
  configured hotkeys, and recording IPC. No separately installed StatusAgent
  or additional background-service owner is required.
- **floating Stop** — the signed recording presenter uses the App's bundled
  processing runtime and restores retry when stopping fails or cannot be
  confirmed. Starting a command is not reported as completed recording work.
- **safe updates and exit** — admitted native commands are drained before
  handoff. Update health requires a prepared native endpoint before commit,
  while command admission stays closed until migration completes.
- **local captions** — the isolated bundled installer can load its trusted
  sibling modules without importing an ambient Python path.
- **visible failures** — unavailable controls are shown as unknown; rejected
  recording actions display an error and are not automatically replayed.

Provider choice, Grok CLI-compatible OAuth, API-key alternatives, and local
Agent credential ownership are unchanged. Recording processing still ends
after transcript and summary. Sharing remains manual-only and requires a
fresh confirmation; it is never a side effect of finishing a recording.

Open the official `yulu-macos-arm64-v0.23.0-rc.11.dmg`, drag `Yulu.app` to
`/Applications`, and launch it there. No development runtime or proxy service
is an installation dependency. Closing the main window keeps native controls
available; quitting Yulu removes them until the App is reopened.

This is a prerelease, not completed installed-product acceptance. Stable
`v0.23.0` may be published only from this exact source after the public DMG
passes the required clean-install, real v0.22.2 upgrade, and update journeys
in #170. The subsequent RC-to-stable update and stable release read-back remain
separate completion gates in #171.
