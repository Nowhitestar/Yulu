# Yulu v0.23.0-rc.21

This candidate retains the Phase 13 migration, native-startup and manual-sharing
repairs and includes both local-transcription fixes found during final clean-Mac
validation:

- **Install the local speech runtime without developer tools.** Runtime Pack
  architecture validation now uses macOS signature metadata instead of the
  unavailable `lipo` developer-tool shim. Homebrew, Xcode and Command Line Tools
  remain unnecessary for the self-contained App. Payload hashes, arm64-only
  architecture, strict signatures and matching signing Team checks still apply.
- **Keep the installed Runtime Pack immutable.** The Python import probe now
  explicitly disables bytecode writes in isolated mode. Installing or warming
  the local model no longer creates cache files that invalidate the next signed
  inventory check.
- **Use the correct installation entry points.** DMG users start from the App
  and its menu bar. A global `yulu` command belongs to a repository/CLI install;
  optional external Agent control uses the documented bundled MCP helper.
- **Retire the old menu-bar App during migration.** Stopping the legacy launchd
  waiter alone could leave its independently launched StatusAgent running. The
  migration now verifies the exact process and its idle state before requesting
  termination. Recovery of an already committed migration never recopies or
  rolls back user data. Active or unidentifiable native work is left untouched.

Install the official signed, notarized DMG by dragging the complete `Yulu.app`
into `/Applications`. Configuration and recordings remain outside the App.
Never patch the signed bundle or reset migration data to work around a failure.

Recording processing ends after transcript and summary commit. Sharing remains
a separate, explicitly confirmed manual action. Audio and Summary Providers do
not silently switch, and no proxy or external Agent is a core install dependency.

The repaired runtime passed targeted regression tests, full source CI and
installed internal-App checks. These do not replace the final public-candidate
download, supported `v0.22.2` upgrade and update/rollback checks under #170.
This is not an accepted stable release. Stable publication requires the exact
accepted candidate source and #171's separate publication/update checks.
