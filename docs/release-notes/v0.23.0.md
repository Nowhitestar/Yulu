# Yulu v0.23.0

Yulu is now a self-contained macOS meeting workspace installed by dragging one
signed and notarized App into `/Applications`.

- **transcription** — local by default, or direct xAI through Grok
  CLI-compatible OAuth when explicitly selected.
- **summary** — direct xAI, Codex, and Claude Code are independent, pinned
  Summary Providers with no silent fallback.
- **conversation** — direct xAI and locally installed Codex, Claude Code,
  Hermes, and OpenClaw remain independent from recording summaries.
- **Calendar** — optional Calendar onboarding links to the authoritative
  Calendar Settings surface and never blocks Core Activation.
- **manual Sharing** — every external share is initiated and confirmed from a
  recording detail page; recording completion never shares automatically.

Download `yulu-macos-arm64-v0.23.0.dmg`, open it, and drag `Yulu.app` to
`/Applications`. The Application Runtime includes the compatible core toolchain;
No proxy service, Agent runtime, Homebrew, host Node, host Python, Xcode, or
Command Line Tools are installation requirements. Existing configuration, recordings,
OAuth custody, optional capability decisions, and migration evidence remain
outside the immutable App and are preserved during replacement.

## Acceptance scope

This stable release uses the exact accepted `v0.23.0-rc.21` source,
`ef9828a3d241acde0d05c8908e1d7b4023878760`, with Sparkle build **1667** (RC21:
1666). No intervening product code is included. Candidate acceptance is recorded
in [#170](https://github.com/Nowhitestar/Yulu/issues/170); stable publication,
public-feed verification and the ordinary whole-App update are recorded
separately in [#171](https://github.com/Nowhitestar/Yulu/issues/171).

On September 15, the project owner accepted physical-Mac closeout with reuse of
the existing real recording/transcription/summary and verified manual-sharing
evidence. The final RC21 check confirmed the signed whole-App replacement,
running Host/Capture, healthy database, ready idle inputs, normal Finder reopen,
and unchanged saved artifacts and migration journal. It did not repeat model
calls, OAuth login or external writes. Current Sharing Readiness must still be
proved in the running Host; retained Share receipts are not fresh connectivity.

**Accepted validation risks:** the exact public RC21 default-local-runtime
fresh-install journey and complete public `v0.22.2` upgrade were **not re-run
end to end**. Earlier clean-install/internal-App/legacy/component results retain
their original scope. Additional cloud, lifecycle and rollback repetitions were
waived, not passed. macOS 13 remains a deployment target, not a tested acceptance
environment. The retained VM is stopped; these waived repetitions do not block
this release or create an automatic follow-up test queue.
