# Yulu v0.24.0

This release restores meeting reminders in the bundled App and makes the daily
workspace easier to navigate.

- **Meeting reminders:** the App starts and supervises the calendar poller,
  reminder scheduler, and meeting detector after startup. Existing enabled
  settings are respected, stopped children recover, and prompts are drained
  before quitting or updating. Google Calendar can find an existing `gog`
  installation outside the bundled runtime's PATH.
- **Settings:** five clear categories replace the crowded settings layout.
  Everyday choices stay visible; permissions, tuning, storage maintenance, and
  other advanced details expand when needed. Existing settings links and saved
  preferences continue to work.
- **Meeting assistant:** a compact conversation header, collapsible history,
  meeting references beside the composer, and optional citation details leave
  more room for the conversation. Agent connector management moves to Settings.
- **Runtime status:** availability is shown by feature, with links to the next
  useful action. Disabled, unconfigured, unchecked, and failed states remain
  distinct; detailed task, scheduler, service, and log tools are under Advanced
  diagnostics.
- **Window:** a unified titlebar removes the top separator and brings navigation,
  search, and recording controls into the top area. Narrow windows keep the main
  controls and conversation composer within reach.
- **Startup:** the native window waits for the rendered application before
  removing its loading surface. Initialization failures and timeouts offer Retry
  instead of leaving an empty window.

## Updating

Use Yulu's update check, or download `yulu-macos-arm64-v0.24.0.dmg`, open it, and
drag `Yulu.app` into `/Applications`. Existing configuration, recordings, provider
selections, and credentials remain outside the App. No new calendar or AI
authorization is required by these interface changes.

## Verification scope

The changes were exercised in the installed native App on a physical Mac,
including cold startup, settings navigation, reminder service ownership, and
configuration preservation. Isolated tests cover delayed application rendering,
reminder scheduling and cleanup, recovery safeguards, and responsive layouts
from 360 to 1440 pixels. Signing, notarization, runtime inventory, public asset
checksums, and the signed update feed are validated by the release pipeline.

A future real meeting's notification delivery and new AI requests were not used
as UI acceptance tests. The complete fresh-install and cross-version migration
matrix was not repeated for this release; macOS 13 remains the deployment target.
