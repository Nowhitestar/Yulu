# Yulu v0.23.0-rc.12

This candidate supersedes RC11 after real public-DMG installation exposed an
acceptance-observer inventory mismatch. The installed App contained both native
recording presenters, but the observer omitted them from its fixed file list.

- **complete inventory verification** — the acceptance observer includes
  `recorder_status` and `meeting_prompt`, while retaining file type, permissions,
  hash, signature, and mounted-to-installed bundle checks. Changed or missing
  presenters still fail validation.
- **same-source acceptance** — the corrected collector and candidate are built
  from the same clean source. RC11 artifacts and tags are not overwritten, and
  diagnostic checks against RC11 do not substitute for formal RC12 acceptance.

The self-contained installation, native recording controls, provider choices,
Grok CLI-compatible OAuth, and API-key alternatives are unchanged. Recording
processing ends with transcript and summary. Sharing remains manual-only and
requires a fresh confirmation; recording completion never shares automatically.

Open the official `yulu-macos-arm64-v0.23.0-rc.12.dmg`, drag `Yulu.app` to
`/Applications`, and launch it there. No development runtime, proxy service,
or separately installed StatusAgent is an installation dependency.

This is a prerelease, not completed installed-product acceptance. Stable
`v0.23.0` may be published only from this exact source after the public DMG
passes the required clean-install, real v0.22.2 upgrade, and update journeys
in #170. The subsequent RC-to-stable update and stable release read-back remain
separate completion gates in #171.
