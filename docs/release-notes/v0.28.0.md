# Yulu v0.28.0

This release redesigns the window around what you do every day: record, read,
and find. Nothing you rely on was removed; the less frequent controls moved one
step back. Questions about meetings now go to the Agent you already use.

- **Two panes:** the recordings list on the left and a reading sheet on the
  right, separated by one hairline. The toolbar keeps only the pane toggle,
  Settings, and Record. Hide the list with the toolbar button or `⌃⌘S`; Yulu
  remembers the choice.
- **One search:** `⌘K`, or the search field above the list, searches
  recordings, summaries, and transcripts and jumps to any settings page. With
  nothing typed, it lists every page.
- **Reading sheet:** a recording opens on its summary, with the transcript in
  the second tab and **Copy Markdown** beside them. **Share** stays up front;
  the summary template, regenerate, re-transcribe, rename, and delete moved to
  the **⋯** menu.
- **Quieter list:** each row shows a title and one line such as
  *Yesterday · 45 min*. A spinner appears only while a recording is processing
  and a warning mark only when it failed; hover for the reason. `j` and `k`
  move between recordings.
- **Settings in place:** Settings opens in the left pane, with Templates, the
  glossary, and Runtime status alongside the five categories. **Back to
  recordings** returns to the meeting you were reading. Voice Input now lives in
  **Settings → Voice Input**, including recent dictation and its original text.
- **Connect an Agent:** **Settings → Connections** can register Yulu's MCP
  server with Claude Code, Codex, and other detected Agents, and test the
  connection. Ask that Agent about your meetings; it keeps its own history.
- **Meeting assistant retired:** the in-app assistant, the Agent Console, and
  the `Fn+Space` voice-question shortcut are gone (ADR-010). Hermes and OpenClaw
  remain available as MCP clients. Dictation and `Fn+Shift` translation are
  unchanged.
- **Themes:** every theme is kept, including Ayu, Paper, and custom colors, on
  one set of semantic color tokens.

## Updating

Use Yulu's update check, or download `yulu-macos-arm64-v0.28.0.dmg` and drag
`Yulu.app` into Applications after recording has finished. Like v0.27.2, the
release is Developer ID-signed but not Apple-notarized; if macOS blocks the
first launch, confirm the download came from the official release page, then
use **System Settings → Privacy & Security → Open Anyway**.

On first launch, retired conversation settings are archived next to your config
as `config.legacy-conversation.<stamp>.json` and removed from the active file.
Dictation cleanup keeps its previous behavior: it stays on only where the
conversation provider was xAI, with the same model. Recordings, history, and
provider credentials are not changed.

## Verification scope

CI ran the web type check, unit tests, and production build and the Python
tests; the release workflow compiled and signed the App and published the DMG
and the signed update feed. The new window was exercised in a browser
against fictional fixture data in light and dark themes, Chinese and English,
and wide and narrow windows. These checks do not cover rendering inside
`Yulu.app` on every supported macOS version; macOS 13 remains the deployment
target.
