# Yulu v0.27.2

- **Recording timer:** reopening the window restores the elapsed time of the
  current recording. Background suspension no longer leaves the timer behind,
  and the next recording starts from zero.
- **Clearer dictation failures:** Chinese and English notices distinguish
  network and certificate errors, timeouts, account authorization, service
  failures, and local-service problems. Notices include a relevant next step,
  stay visible longer, and only claim the audio was saved when confirmed.
- **Updates from local repair builds:** valid local repair versions can return
  to the stable channel while signature checks and downgrade protection remain
  enforced.

## Installation and updates

This release is **Developer ID-signed but not Apple-notarized**. It retains the
same signing identity and Sparkle update keys. Checksums and GitHub build
provenance remain available for all executable release assets.

Use Yulu's update check, or download `yulu-macos-arm64-v0.27.2.dmg` and drag
`Yulu.app` into Applications after recording has finished. If macOS blocks the
first launch because Apple cannot check it for malicious software, confirm
that your download came from this official release page, then open
**System Settings → Privacy & Security → Open Anyway**. See
[Apple's instructions](https://support.apple.com/102445).

Older local repair builds that cannot finish their in-app update can use the
DMG. Settings, recordings, history, and provider credentials remain outside
the App.

## Verification scope

Regression checks cover recording timestamps across window remounts, delayed
callbacks and new sessions, categorized dictation errors, and accepted and
rejected update transitions. Release checks still validate Developer ID
signatures, bundled runtime integrity, signed update archives and feeds,
checksums, and build provenance. These checks do not constitute Apple
notarization or a complete clean-install and cross-version migration matrix.
