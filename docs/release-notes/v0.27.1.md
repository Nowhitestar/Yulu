# Yulu v0.27.1

- **Recording timer:** reopening the Yulu window now restores the current
  recording's elapsed time. The timer uses the capture service's start time,
  catches up after background suspension, and resets for the next recording.
- **Clearer dictation failures:** Chinese and English notices distinguish
  network and certificate errors, timeouts, account authorization, service
  failures, and local-service problems. Each notice offers a relevant next
  step, stays visible longer, and only says the recording was saved when that
  has been confirmed.
- **Updates from local repair builds:** a valid locally patched version can
  return to the stable update channel. Signed-target verification, increasing
  build numbers, and downgrade protection remain enforced.

## Updating

Use Yulu's update check, or download `yulu-macos-arm64-v0.27.1.dmg` and replace
`/Applications/Yulu.app` after recording has finished. If an older local repair
build cannot complete its update, use the DMG. Settings, recordings, history,
and provider credentials remain outside the App.

## Verification scope

Regression coverage includes window remounts, delayed timer callbacks, new
recording sessions, capture timestamps over IPC, categorized dictation errors,
native failure notices, and valid and rejected update transitions. The local
repair build was installed and its startup, capture readiness, and preserved
configuration and recordings were checked on a physical Mac. This does not
claim a new fresh-install or full cross-version migration matrix.
