# Yulu v0.23.0-rc.13

This candidate supersedes RC12 after public appcast read-back exposed a minimum
macOS metadata mismatch. The native code already required macOS 13, but the App
and Capture bundles did not declare that floor and the appcast reported 10.13.

- **consistent macOS requirements** — App and Capture builds explicitly declare
  `LSMinimumSystemVersion=13.0.0`, matching the existing macOS 13+ product floor.
- **release metadata gate** — runtime and generated appcast verification reject
  missing or incorrect minimum-system declarations before publication. Existing
  full-DMG URL, size, signature, and no-delta checks remain in place.

The public DMG remains self-contained: drag `Yulu.app` to `/Applications` and
launch it there. Grok CLI-compatible OAuth and explicit API-key alternatives
are unchanged. Recording Processing ends with transcript and summary; Share
remains manual-only with a fresh confirmation.

RC12 assets and tags are preserved. This is a prerelease, not completed
installed-product acceptance. The corrected collector and candidate must come
from the same clean source. macOS 13 remains the deployment target, not a formal
acceptance environment; required real-install journeys run on macOS 14+ arm64.
Stable `v0.23.0` remains gated on #170 accepting this exact RC13 source, followed
by the separate stable publication and RC-to-stable update checks in #171.
