# Yulu v0.23.0-rc.16

RC16 repairs the containing-App capture permission declarations found missing
during public RC15 fresh-install acceptance. It continues the self-contained
drag-to-Applications candidate line and retains RC15's database initialization
repair.

- **Correct permission subject** — the product App now declares microphone,
  system-audio and screen-capture usage descriptions plus the hardened-runtime
  audio-input entitlement. Capture keeps its existing identity and declarations;
  macOS can attribute its authorization requests to the containing App.
- **Package guards** — Application Runtime verification rejects missing, blank
  or wrong-typed descriptions in either bundle and missing or non-true audio-input
  entitlements on either signed executable. Existing Node signing checks remain.
- **Regression coverage** — tests first reproduced acceptance of deficient
  packages, then verified rejection. The new verifier also rejects the original
  public RC15 App for its missing containing-App description.

Grok CLI-compatible OAuth, explicit provider/model selection and data-path
disclosures are unchanged. Recording Processing ends with transcription and
summary; manual Sharing still requires a fresh confirmation. Conversation and
Calendar remain optional capabilities.

Correct declarations permit the normal macOS authorization flow; they do not
grant permission or prove captured signal. RC15's failed recording and earlier
candidate assets, tags and partial evidence remain preserved. Do not edit or
re-sign an installed release, reset permissions to compensate for missing bundle
metadata, or treat green connection probes as successful recording evidence.

This prerelease still requires real fresh-install and v0.22.2 upgrade evidence,
including permission recovery, recording, transcription, the selected summary,
manual sharing and lifecycle checks. Source and package tests are not installed
acceptance. The collector and candidate must come from the same clean source.
macOS 13 remains the deployment target, not a formal acceptance environment;
required journeys run on macOS 14+ arm64. Stable v0.23.0 remains gated on #170
accepting this exact RC16 source and the separate publication/update checks in #171.
