# Yulu v0.23.0-rc.20

This candidate consolidates the Phase 13 physical-install, startup and manual
sharing repairs after testing the complete batch in the installed macOS App.

- **Recover existing installations** — prepare the current configuration and
  database schema before readiness checks, retain migration lineage and original
  recordings, and transfer service ownership to the bundled Host and Capture
  without restarting a committed migration or interrupting a recording.
- **Open the complete interface** — recover a late Host startup and present the
  embedded UI automatically after whole-App replacement, without resizing,
  clearing caches or patching the signed App.
- **Use the selected Codex Notion connection** — discover the runtime within its
  own bounded startup budget and verify actual connector responses. Yulu neither
  copies Agent credentials nor substitutes another Agent or model.
- **Keep the complete summary** — preserve a leading Markdown heading when
  creating the Notion page and verify the complete confirmed summary, exact
  destination and external receipt. A missing heading is not accepted as success.
- **Resolve an uncertain share without resending** — the recording Share dialog
  now offers explicit read-only receipt reconciliation. It preserves the original
  action, summary and receipt; changed connections, mismatches, timeouts and
  abandoned actions cannot produce a false successful outcome.

Recording processing still ends after transcript and summary commit. All
external sharing requires a separate manual confirmation, including a warning
before repeating an already verified summary. There is no automatic resend,
provider fallback or dependency on a proxy service. xAI, Codex and Claude Code
remain separately selected providers; external provider restrictions are not
bypassed by this release.

Install by opening the official signed, notarized DMG and dragging `Yulu.app` to
`/Applications`, replacing the complete previous App. The core runtime is
self-contained; host Node, Python, Homebrew, Xcode and Command Line Tools are not
installation prerequisites. Configuration and recordings remain outside the
immutable App. Do not edit migration journals or reprocess historical meetings
to validate an update.

The internal repair batch passed full CI, whole-App replacement, original
receipt reconciliation and one fresh synthetic manual Notion share with complete
content read-back. These results are scoped to that internal App. Final public
DMG, fresh-install, supported `v0.22.2` upgrade and update/rollback results remain
separate acceptance evidence under #170; stable promotion follows only after the
exact candidate source is accepted and #171's checks pass. macOS 14+ Apple Silicon
is the formal acceptance environment; macOS 13 remains a deployment target.
