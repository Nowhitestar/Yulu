### Upgrade note for v0.17.x

v0.17.x shipped an updater that only recognizes the retired pkg asset. Upgrade
once through the current one-line installer, which bridges to the signed,
notarized, stapled runtime zip and verifies its checksum:

```bash
curl -fsSL https://raw.githubusercontent.com/Nowhitestar/Yulu/main/install.sh | bash
```

After this bridge, use `yulu update` normally. The v0.18 runtime carries the zip
installer helper; pinned updates do not execute mutable installer code from
`main`.
