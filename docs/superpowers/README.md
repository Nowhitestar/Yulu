# Historical design and implementation records

These specs and plans retain their original paths so implementation references,
ADRs, and test provenance remain traceable. The directory name does not select a
workflow or require any framework or subagent.

Follow the current request and [Engineering Workflow](../../CLAUDE.md#engineering-workflow).
Technical decisions and acceptance scenarios remain useful evidence, subject to
later ADRs and actual code. Old steps and unchecked boxes are not a current task
queue; do not rerun completed work merely to update them.
