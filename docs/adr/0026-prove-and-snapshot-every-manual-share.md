# Prove the destination and snapshot every manual Share

Sharing Readiness requires a selected Agent Connection, proven Connector access,
an explicit destination saved and read back, and a verified Test Share; discovered
or default target text never qualifies. Every production Share Action then pins
its summary, connection, and destination behind a fresh confirmation. A previous
verified receipt triggers a duplicate warning but permits a new explicit action,
while an Unknown Outcome remains fenced from ordinary retry.
