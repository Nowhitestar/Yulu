# Quick Task 260625-006: Agent CLI Session Migration

## Goal

Move Agent Console closer to the user's desired Agent-native runtime:

- Yulu UI startup ensures a background session for the selected Agent.
- Background work such as summary generation and sharing records into that background Agent session.
- Ask Meetings continues to create/use separate persisted conversation sessions.
- Summary generation uses the same selected Agent runtime resolver as Ask Meetings.
- Share actions route through the selected Agent CLI/plugin path instead of Yulu's legacy connector sender.

## Assumptions

- Codex/Claude are currently invoked as CLI subprocesses; there is no stable long-running session IPC in this repo yet.
- A "Yulu background session" is therefore a persisted Yulu session record plus consistent Agent CLI context for each background action.
- True provider-native resume/session IDs can be added later behind the same store.
- Yulu owns local capture, STT, artifacts, prompts, terms, search, and session records.

## Plan

1. Extract reusable Agent session store.
   - Verify: existing Agent session router tests still pass.

2. Ensure a background Agent session when the UI server starts and expose it in Agent Console overview.
   - Verify: server/router tests can inspect session creation.

3. Route manual summary generation through the selected Agent runtime.
   - Verify: recording router tests assert direct Agent command when provider is selected.

4. Route summary sharing through selected Agent CLI prompts and record outputs to the background session.
   - Verify: tests assert Notion/Zulip sends no longer call `send_summary.py` in the Agent Console path.

5. Validate and smoke.
   - Verify: typecheck, focused tests, build, and browser smoke on `http://127.0.0.1:7780/agent-console`.

## Result

- Added a shared Agent session store with `ask` and `background` purposes.
- UI server startup now ensures a background session for the selected Agent when a runtime is available.
- Summary generation resolves the selected Agent runtime and records background session messages.
- Summary sharing now validates Console plugin filters and the selected Agent's plugin configuration, then prompts the Agent CLI instead of calling Yulu's legacy `send_summary.py`.
- Recording detail and inbox share targets now use the same selected Agent + Console plugin layer as Agent Console.
- Settings > Integrations no longer renders legacy Notion/Zulip output configuration controls; it points users to Agent Console.
- `agent_queue_worker.py` and host capability probes now fall back from `llm.command: null` to `llm.agent.provider` for Codex/Claude.
