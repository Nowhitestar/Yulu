# 260625-008 Agent Session CLI and Settings Polish

## Goal

Fix the last Agent Console product mismatches:

- Local CLI detection must find user-installed Claude, Hermes, and OpenClaw.
- Ask Meetings "new chat" must create a fresh Yulu ask session and provider-native session, while history resumes existing sessions.
- Agent Console must model two session classes: ask sessions and Yulu background sessions.
- Settings must stop exposing legacy Summary LLM and output connector controls; integrations should point output/plugin state to Agent Console and keep only Yulu-owned calendar scheduling settings.

## Assumptions

- Codex remains the default auto-detected runtime when present.
- Claude can use `--print --session-id <uuid>` for stable non-interactive sessions.
- Hermes supports one-shot/resume via `hermes chat -Q --source yulu --query ...` and `--resume`.
- OpenClaw supports explicit sessions through `openclaw agent --json --session-id ... --message ...`; its gateway/local provider health is still owned by OpenClaw.

## Verification

- Unit tests for Agent Console detection, session creation/resume behavior, and settings migration.
- Typecheck and focused Vitest suite.
- Restart local dev UI on port 7780 for browser verification.
