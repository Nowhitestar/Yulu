# Quick Task 260625-004 Summary: Agent Console Agent-Scoped Plugins

## Shipped

- Console plugin state is now Agent-scoped:
  - Yulu stores which plugins are added to the Console.
  - The selected Agent determines whether each added plugin is configured.
  - Notion, Zulip, Calendar, and Summary now render from this combined state.
- Switching the underlying Agent changes the visible capability status.
- "去配置" no longer navigates to the legacy Yulu AI integration settings; it returns an Agent CLI configuration instruction and keeps credentials outside Yulu.
- Recent task cards now show the next action/result state only.
- Meeting detail no longer renders the right-side system status inspector.
- Ask Meeting assistant answers render Markdown.

## Notes

- The legacy AI integration settings remain in the codebase for compatibility, but Agent Console no longer treats them as the source of truth for current AI capabilities.
- The Agent configuration action is intentionally non-credentialed: Yulu tells the user to configure the plugin in the selected Agent and then re-detects state.
