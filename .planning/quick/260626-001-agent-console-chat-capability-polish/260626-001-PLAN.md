# 260626-001 Agent Console Chat And Capability Polish

## Goal

Polish Agent Console without changing the underlying agent/runtime architecture:

1. Make Ask Meeting feel like a persistent Agent session workspace.
2. Improve session history ergonomics using existing `agentSessions` APIs.
3. Unify Summary, Notion, Zulip, and Calendar capability rows around one interaction pattern.

## Constraints

- Reuse existing tRPC routers and persisted session data.
- No new dependencies.
- Keep the local scheduler boundary intact.
- Keep changes scoped to Agent Console UI and tests unless a shared bug appears.

## Verification

- Targeted Agent Console web tests.
- `npm run typecheck`
- `npm test`
- `npm run build`
- `make dev-install`
- `python3 yulu/scripts/doctor.py --json`

## Result

- Ask Meeting now renders as a session workspace with a searchable, grouped history rail, a current-session header, and folded source summaries.
- Summary, Notion, Zulip, and Calendar capability rows now share one stacked row pattern: title/status/remove, current target/value, and a single change/configure action.
- Summary template selection moved into the same modal interaction pattern as destination/calendar selection.
- Verified with targeted Agent Console tests, typecheck, full UI test suite, production build, dev-install, doctor, and a Playwright render smoke.

## Follow-up

- Fix the new-session empty state so the composer stays in the normal bottom position.
- Add basic session management actions: rename, delete, pin, and archive.

## Follow-up Result

- New-session empty state now uses the regular chat thread + bottom composer layout.
- Session store/router now support rename, delete, pin, and archive; default session list hides archived sessions and sorts pinned sessions first.
- History rows now expose a compact action menu for those session actions.

## Responsive Follow-up Result

- Agent Console now marks the root shell so only this route can enter a compact desktop mode.
- At 761-1499px, the app sidebar becomes icon-only, Agent Console switches from three columns to two columns, and the Agent capability rail becomes a drawer opened from the mode bar.
- Verified the compact layout at 1280px and 1440px with Playwright screenshots, including the capability drawer state.

## Sidebar Polish Result

- Compact Agent Console sidebar now expands on hover, hides Local Engine, and keeps the health dot under the health icon while collapsed.
- Mobile bottom navigation now fits all workspace/system icons in one row.
- Top breadcrumbs are centered globally, and the compact Agent Console left rail matches the breadcrumb width.
- Ask Meeting now opens as a fresh draft session by default; history sessions resume only after explicit selection.
