## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.json → probes (llm.command) | User-editable JSON supplies the llm command; its head token is resolved+statted, NEVER executed |
| login shell → probes | The user's `$SHELL -lc` is spawned to read the login-shell PATH; the queried binary name is a fixed Yulu-known token |
| daemon interpreter → probes | The daemon's python3 (plist __PYTHON__) runs an `import <module>` probe with a fixed module name |
| filesystem (model roots) → scan | Fixed, well-known model directories are globbed; no user-supplied path crosses here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation/Tampering | probe_llm_command resolving the configured command | mitigate | The probe resolves+stats the binary (`resolve_on_login_path(llm_command[0])`) and NEVER runs it — no `subprocess.run(llm_command, input=...)`, no arbitrary-command execution. Acceptance criterion asserts `input=` is absent from probe_llm_command and that only a `command -v` argv is issued. This is the core ASVS-L1 mitigation for the phase's highest-value surface. |
| T-03-02 | Tampering (command injection) | resolve_on_login_path `$SHELL -lc 'command -v X'` | mitigate | List-form `subprocess.run([shell, "-lc", "command -v " + binary], ...)` — never `shell=True` on the outer call. The interpolated `binary` is a fixed Yulu-known identifier (claude / whisper-cli / the resolved llm.command head), not free-form user input; `command -v` is a builtin lookup, not execution. |
| T-03-03 | Tampering (path traversal) | scan_models globbing model roots | mitigate | Globs only the three fixed roots (`~/.config/yulu/models`, whisper.cpp dir, `~/.cache/huggingface/hub`); no `..`, no user-supplied path segment, no symlink-follow beyond the user's own caches. Stat/size only — no read of model contents. |
| T-03-04 | Information Disclosure | probe error details surfaced in `detail` | mitigate | Probes return a short `detail` (version or stderr-first-line) and degrade to `absent(detail)` on failure — never raise, never echo full environment/paths (doctor "never raises" contract + ASVS V7). |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | N/A this plan — stdlib-only Python (`os`/`shutil`/`subprocess`/`glob`/`dataclasses`/`enum`), zero package installs. No `[ASSUMED]`/`[SUS]` packages → no Package Legitimacy checkpoint required. |
