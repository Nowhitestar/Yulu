## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| capabilities router → CapabilitiesSection | the section RENDERS server data; it must treat the report as display-only and never echo it into a command |
| user → Refresh button | user-triggered refetch; bounded by the router's own timeout (04-01) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-XSS | Tampering | rendering `resolved_path`/`detail` from the report | mitigate | Render report strings as React text children only (JSX auto-escapes); never `dangerouslySetInnerHTML`. Paths/detail are displayed, not interpolated into HTML or any command. |
| T-04-REFRESH | Denial of Service | Refresh button spamming doctor | accept | Single-user local UI; the router's ~10s timeout + TanStack Query in-flight dedupe bound repeated clicks. No additional rate-limit needed. |
| T-04-INFO | Information Disclosure | capability paths shown in UI | accept | Local-first single-user surface (127.0.0.1); paths/versions are the user's own. No secrets (Yulu holds no keys). |
| T-04-SC | Tampering | npm installs | mitigate | No new packages (existing React/tRPC/Vitest only). No legitimacy checkpoint required. |
</threat_model>
