<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| audio_daemon.sock → PermissionModel | Daemon liveness/permission status read over the local Unix socket |
| tccutil / brew argv → subprocess | TCC reset and Homebrew commands executed by the seams |
| OS TCC database | The actual access-control boundary for capture — reported, never bypassed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering/Elevation | tccutil + brew subprocess calls (permission/dependency seams) | mitigate | List-form `subprocess.run([...], check=False)` only; capability tokens are fixed strings mapped internally to scope names — no external value is interpolated into a command (02-RESEARCH.md:571). Acceptance criterion greps for `shell=True` absence. |
| T-02-06 | Elevation of Privilege | PermissionModel attempting to GRANT TCC programmatically | mitigate | By design PermissionModel only REPORTS status (socket probe) and at most RESETS a stale grant via tccutil; it never attempts to grant capture permission — impossible by macOS design and explicitly forbidden (ASVS V4, 02-RESEARCH.md:562). check() has no grant path. |
| T-02-07 | Information Disclosure | Error messages from brew/tccutil failures leaking paths/PII | mitigate | DependencyManager.install raises a fixed message ("Homebrew not available"); is_available returns a bool, never the raw brew stderr; PermissionModel returns neutral status strings (ASVS V7). |
| T-02-08 | Tampering | Socket world-access to the daemon control channel | accept | Out of scope this phase: the socket is already `chmod 0o600` with per-fd timeouts (audio_daemon.swift:630) — unchanged here (02-RESEARCH.md:574). PermissionModel only sends the read-only `{"action":"status"}` probe. |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | N/A — stdlib-only Python, zero installs (02-RESEARCH.md:93-97). No `[ASSUMED]`/`[SUS]` packages → no legitimacy checkpoint. DependencyManager *wraps* brew but installs nothing during planning/execution of this phase's own code. |
</threat_model>
