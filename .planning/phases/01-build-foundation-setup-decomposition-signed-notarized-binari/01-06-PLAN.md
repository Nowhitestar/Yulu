<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions secrets -> CI runner | The signing cert (.p12) and App Store Connect API key (.p8) cross into the runner; leakage would let an attacker sign as Yulu. |
| CI runner -> Apple notary service | The signed bundle is submitted to Apple for malware scan + ticket issuance. |
| Release asset -> user machine | Users trust the zip; integrity must be provable independently of the download channel. |
| Reusable workflow OIDC token | The attestation is signed by the workflow's OIDC identity; wrong permissions = no/forged provenance. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-15 | Information Disclosure | signing cert / API key leakage into repo or logs | mitigate | Credentials live ONLY in GitHub Actions secrets (D-08); decoded to RUNNER_TEMP, never echoed, no set -x around them; acceptance greps for hardcoded secrets and scans run logs; ephemeral keychain torn down with if-always cleanup (Pattern 3). |
| T-01-16 | Tampering | tampered release asset served to users | mitigate | actions/attest-build-provenance@v4 mints SLSA provenance verifiable with gh attestation verify (BUILD-04/SC-4); plus the existing SHA-256 checksum and the notarization staple. Three independent integrity signals. |
| T-01-17 | Tampering / trust | un-notarized binary warned by Gatekeeper | mitigate | notarytool submit --wait (Apple malware scan) + stapler staple of the .app directory before zipping (Pitfall 4); proven by spctl -a -vvv on a clean machine (SC-2, Task 3). Replaces the --timestamp=none + xattr smell. |
| T-01-18 | Spoofing | forged/absent provenance due to missing OIDC permissions | mitigate | id-token write + attestations write declared on the publish job; Task 3 confirms the reusable workflow actually mints the token (Assumption A4). If inheritance fails, permissions are declared explicitly on the job (already done). |
| T-01-19 | Elevation of Privilege | keychain left populated on a shared runner | mitigate | security delete-keychain in an if-always cleanup step removes the imported identity even on failure (Pattern 3, RESEARCH Security Domain). |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | No language-package installs. First-party Apple tools (codesign/notarytool/stapler/ditto/security) + first-party actions/attest-build-provenance@v4 (verified v4.1.0) + actions/checkout@v4. Package Legitimacy Audit is N/A (RESEARCH). No [ASSUMED]/[SUS] package introduced. The [SLOP] class is absent. |
</threat_model>
