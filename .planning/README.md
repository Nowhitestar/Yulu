# Historical planning archive

This directory preserves dated project maps, requirements, decisions, plans, and
verification evidence. Its configuration, commands, workflow preferences, phase
positions, and unchecked tasks do not define the current execution queue.

Follow the current request and [Engineering Workflow](../CLAUDE.md#engineering-workflow).
Use current code, `CONTEXT.md`, accepted ADRs, and relevant GitHub issues to decide
what is still needed. Preserve useful evidence, but check its source, environment,
and scope before reusing it. Do not regenerate repository instructions or rerun
completed phases from this archive.
